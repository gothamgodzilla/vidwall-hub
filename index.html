macOS Tahoe 26+

Build dynamic lock-screen sources from your own videos.

Vidwall Hub imports local MP4 and MOV files into Apple's wallpaper resource folders, then refreshes wallpaper services so your clips are available in System Settings.

Get Latest Release About Vidwall

How it works

  1. Load wallpaper manifest entries from your user library.
  2. Create the Vidwall Videos category when missing.
  3. Write new asset entries and generated thumbnails.
  4. Copy or remux videos into system wallpaper resources.
  5. Restart wallpaper services so new assets appear instantly.

URL automation

Trigger imports directly from a file path:

vidwallhub://open?file=/file/to/path/video.mp4

Brew install

brew install --cask jaywcjlove/tap/vidwall-hub
